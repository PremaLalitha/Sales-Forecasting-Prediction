# Retail Sales Forecasting & Prediction using Machine Learning and Power BI

## Project Overview

This project analyzes historical retail sales data and uses Machine Learning to predict future monthly sales.

The project combines **Python, Pandas, Scikit-learn, and Power BI** to perform data preparation, sales analysis, forecasting, model evaluation, and interactive visualization.

A Linear Regression model is used to predict future sales based on time-related features and previous month's sales.

---

## Objectives

- Analyze historical retail sales data.
- Prepare sales data for time-series forecasting.
- Calculate monthly sales trends.
- Build a Machine Learning model for sales prediction.
- Evaluate the prediction performance.
- Forecast sales for the next 6 months.
- Compare actual sales with predicted sales.
- Create an interactive Power BI dashboard.
- Provide business insights from sales data.

---

## Dataset

The dataset contains **1,096 daily records** from **2023 to 2025**.

### Dataset Columns

- OrderID
- OrderDate
- CustomerID
- Category
- Region
- Product
- Sales
- Quantity
- Profit
- Discount
